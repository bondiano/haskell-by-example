# Начало работы

## Цели главы

В этой главе мы настроим окружение для разработки на Haskell, познакомимся с инструментами и решим несколько упражнений, проверяя ответы с помощью тестов.

## Установка окружения

### GHCup

[GHCup](https://www.haskell.org/ghcup/) — официальный установщик инструментов Haskell. Он управляет версиями компилятора GHC, сборщика Stack и языкового сервера HLS.

Установите GHCup, следуя инструкциям на сайте:

```text
$ curl --proto '=https' --tlsv1.2 -sSf https://get-ghcup.haskell.org | sh
```

В процессе установки GHCup предложит установить GHC, Stack и HLS. Соглашайтесь на все компоненты.

После установки проверьте, что всё работает:

```text
$ ghc --version
The Glorious Glasgow Haskell Compilation System, version 9.6.6

$ stack --version
Version 3.7.1 ...
```

### Stack

**Stack** — сборщик проектов на Haskell. Он обеспечивает воспроизводимые сборки: каждый проект привязан к конкретному набору пакетов (resolver), где все библиотеки гарантированно совместимы друг с другом.

В этой книге мы используем Stack для сборки и запуска тестов. Если вы уже установили Stack через GHCup, дополнительная установка не требуется.

### Редактор

Для работы с Haskell подойдёт любой редактор с поддержкой [HLS (Haskell Language Server)](https://haskell-language-server.readthedocs.io/):

- **VS Code** — расширение [Haskell](https://marketplace.visualstudio.com/items?itemName=haskell.haskell).
- **Neovim** — через `nvim-lspconfig` + `haskell-tools.nvim`.
- **Emacs** — `haskell-mode` + `lsp-mode` или `eglot`.

HLS обеспечивает автодополнение, подсказки типов, переход к определению и автоматический импорт модулей.

> Для корректной работы HLS рекомендуется открывать в редакторе директорию конкретной главы (например, `exercises/chapter02`), а не корень всего репозитория.

## Структура проекта

Откройте директорию `exercises/chapter02`. Вот что в ней находится:

```text
chapter02/
├── package.yaml          ← описание пакета (hpack)
├── src/
│   └── Euler.hs          ← исходный код примеров
├── test/
│   ├── Spec.hs           ← тесты
│   └── MySolutions.hs    ← ваши решения упражнений
└── no-peeking/
    └── Solutions.hs      ← эталонные решения (не подсматривать!)
```

### package.yaml

Файл `package.yaml` описывает пакет в формате [hpack](https://github.com/sol/hpack). При сборке hpack автоматически генерирует из него `.cabal`-файл. Вот ключевые секции:

```yaml
name: chapter02
version: 0.1.0.0

dependencies:
  - base >= 4.18 && < 5    # стандартная библиотека

library:
  source-dirs: src          # модули библиотеки

tests:
  chapter02-tests:
    main: Spec.hs
    source-dirs: test
    dependencies:
      - chapter02            # зависимость от самой библиотеки
      - hspec                # тестовый фреймворк
```

Секция `dependencies` в корне — зависимости, общие для всех компонентов. Секция `library` описывает библиотеку (код в `src/`). Секция `tests` описывает тестовые наборы.

### stack.yaml

В корне репозитория лежит `stack.yaml` — конфигурация Stack для всего проекта:

```yaml
resolver: lts-22.43       # набор пакетов (включает GHC 9.6.6)

packages:
  - exercises/chapter02    # список пакетов проекта
```

**Resolver** (решатель) — это снапшот Stackage: фиксированный набор версий пакетов, проверенных на совместимость. Когда в `package.yaml` вы указываете зависимость `hspec`, Stack берёт ту версию `hspec`, которая входит в снапшот `lts-22.43`.

### Модули

Каждый файл `.hs` содержит один модуль. Имя модуля должно совпадать с путём к файлу:

```haskell
-- Файл: src/Euler.hs
module Euler where

answer :: Int -> Int
answer limit = sum [x | x <- [1 .. limit - 1], x `mod` 3 == 0 || x `mod` 5 == 0]
```

Модуль `Euler` экспортирует функцию `answer`. Другие модули могут импортировать её:

```haskell
import Euler (answer)
```

## Знакомство с GHCi

**GHCi** — интерактивный интерпретатор Haskell. Запустите его из директории `exercises/chapter02`:

```text
$ cd exercises/chapter02
$ stack ghci
```

Stack загрузит модули проекта и откроет приглашение GHCi:

```text
> answer 10
23

> answer 1000
233168
```

### Полезные команды GHCi

| Команда | Действие |
|---------|----------|
| `:type expr` (или `:t`) | Показать тип выражения |
| `:info name` (или `:i`) | Информация о типе, классе или функции |
| `:reload` (или `:r`) | Перезагрузить изменённые модули |
| `:quit` (или `:q`) | Выйти из GHCi |

Попробуйте:

```text
> :type answer
answer :: Int -> Int

> :type sum
sum :: (Foldable t, Num a) => t a -> a

> :info Int
type Int :: *
data Int = GHC.Types.I# GHC.Prim.Int#
    -- Defined in 'GHC.Types'
instance Eq Int -- Defined in 'GHC.Classes'
instance Ord Int -- Defined in 'GHC.Classes'
instance Show Int -- Defined in 'GHC.Show'

```

Команда `:type` особенно полезна — она помогает понять, с каким типом вы работаете, не заглядывая в документацию.

## Тестирование с hspec

В этой книге мы используем [hspec](https://hspec.github.io/) — тестовый фреймворк для Haskell. Посмотрим на тесты в `test/Spec.hs`:

```haskell
module Main where

import Test.Hspec
import Euler (answer)
import MySolutions (diagonal, circleArea, collatzLength)

main :: IO ()
main = hspec $ do
  describe "Euler — сумма кратных" $ do
    it "ниже 10 равна 23" $
      answer 10 `shouldBe` 23

    it "ниже 1000 равна 233168" $
      answer 1000 `shouldBe` 233168

  describe "diagonal" $ do
    it "диагональ 3×4 равна 5" $
      diagonal 3 4 `shouldBe` 5.0
  ...
```

Структура проста:

- `describe` — группирует связанные тесты.
- `it` — один тест с описанием на естественном языке.
- `shouldBe` — проверяет равенство результата и ожидаемого значения.

Запустите тесты:

```text
$ stack test
```

Тесты для `answer` пройдут, а остальные упадут с ошибкой `Prelude.undefined` — это ожидаемо, потому что функции в `MySolutions.hs` ещё не реализованы:

```text
Euler — сумма кратных
  ниже 10 равна 23 [✔]
  ниже 1000 равна 233168 [✔]
diagonal
  диагональ 3×4 равна 5 [✘]
```

По мере решения упражнений тесты начнут проходить.

## Решаем вместе: задача Эйлера №1

Прежде чем переходить к упражнениям, разберём пример, который уже реализован в `src/Euler.hs`.

**Задача Эйлера №1:** найти сумму всех натуральных чисел ниже 1000, которые кратны 3 или 5.

```haskell
answer :: Int -> Int
answer limit = sum [x | x <- [1 .. limit - 1], x `mod` 3 == 0 || x `mod` 5 == 0]
```

Разберём эту строчку по частям:

1. **`answer :: Int -> Int`** — сигнатура типа. Функция принимает `Int` и возвращает `Int`. Сигнатуры необязательны (компилятор выведет тип сам), но полезны как документация.

2. **`[x | x <- [1 .. limit - 1], ...]`** — генератор списка (list comprehension). Читается так: «список всех `x`, где `x` берётся из диапазона от 1 до `limit - 1`...»

3. **`x \`mod\` 3 == 0 || x \`mod\` 5 == 0`** — ...и `x` делится на 3 или на 5. Оператор `` `mod` `` — остаток от деления. Обратные кавычки превращают функцию в инфиксный оператор: `mod x 3` и `` x `mod` 3 `` — одно и то же.

4. **`sum`** — складывает все элементы списка.

Проверим в GHCi:

```text
> answer 10
23

> [x | x <- [1..9], x `mod` 3 == 0 || x `mod` 5 == 0]
[3,5,6,9]

> sum [3,5,6,9]
23
```

## Упражнения

Решения пишите в файле `test/MySolutions.hs`. После каждого упражнения запускайте `stack test`, чтобы проверить ответ.

1. **(Лёгкое)** Реализуйте функцию `diagonal`, которая вычисляет длину диагонали (гипотенузу) прямоугольного треугольника по двум катетам. Используйте теорему Пифагора и функцию `sqrt`.

    ```haskell
    diagonal :: Double -> Double -> Double
    ```

    ```text
    > diagonal 3 4
    5.0
    ```

2. **(Лёгкое)** Реализуйте функцию `circleArea`, которая вычисляет площадь круга по радиусу. Используйте константу `pi` (доступна из `Prelude`).

    ```haskell
    circleArea :: Double -> Double
    ```

    ```text
    > circleArea 10
    314.1592653589793
    ```

3. **(Среднее)** Реализуйте функцию `collatzLength`, которая возвращает количество шагов в [последовательности Коллатца](https://ru.wikipedia.org/wiki/Гипотеза_Коллатца) до достижения 1.

    Правила последовательности:
    - Если число чётное — делим на 2.
    - Если нечётное — умножаем на 3 и прибавляем 1.
    - Повторяем, пока не получим 1.

    Например, для числа 6: 6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1 — **8 шагов**.

    ```haskell
    collatzLength :: Int -> Int
    ```

    *Подсказка:* используйте рекурсию и guards (охранные выражения). Функция `even :: Int -> Bool` проверяет чётность.
