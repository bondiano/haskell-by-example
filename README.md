# Haskell by Example

Интерактивная книга для изучения Haskell на практике. Каждая глава содержит теорию и упражнения с тестами.

## Содержание

1. Введение
2. Начало работы
3. Функции и записи
4. Сопоставление с образцом
5. Рекурсия, map и свёртки
6. Классы типов
7. Аппликативная валидация
8. Монады
9. Монада эффектов
10. Асинхронные эффекты
11. Интерфейс внешних функций (FFI)
12. Приключения с монадами
13. Графика
14. Генеративное тестирование
15. Предметно-ориентированные языки
16. GADTs и семейства типов
17. Линзы и оптики
18. Веб-приложение с базой данных

## Требования

- [Stack](https://docs.haskellstack.org/) (resolver: lts-22.44)
- [mdBook](https://rust-lang.github.io/mdBook/) (для сборки книги)

## Быстрый старт

```bash
# Сборка всех упражнений
./scripts/build-all.sh

# Запуск тестов
./scripts/test-all.sh

# Сборка книги (mdBook)
mdbook build
```

## Структура проекта

```
text/           # Главы книги (Markdown)
exercises/      # Упражнения по главам (Haskell + Stack)
scripts/        # Скрипты сборки и тестирования
```
