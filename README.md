# Haskell by Example

Интерактивная книга для изучения Haskell на практике, вдохновлённая "PureScript by Example". Каждая глава содержит теорию и упражнения с автоматическими тестами. Все материалы на **русском языке**.

Книга построена вокруг **сквозного проекта** (task tracker), который эволюционирует от чистых функций до REST API на протяжении всех глав.

## Содержание

### Часть I: Основы (главы 1–6)
1. Введение в Haskell
2. Начало работы с функциями
3. Функции высшего порядка и композиция
4. Алгебраические типы данных
5. Рекурсия и структурная индукция
6. Классы типов и полиморфизм

### Часть II: Эффекты и обработка ошибок (главы 7–10)
7. Ввод-вывод и IO-монада
8. Обработка ошибок (Maybe, Either)
9. Ленивые вычисления и производительность
10. Тестирование (hspec, QuickCheck)

### Часть III: Мощные абстракции (главы 11–14)
11. Функторы и их применение
12. Аппликативные функторы
13. Монады и монадические трансформеры
14. Работа с JSON (Aeson)

### Часть IV: Реальные приложения (главы 15–17)
15. Организация Haskell-проектов
16. Параллелизм и конкурентность (async, STM)
17. Веб-приложения и базы данных (Servant, Persistent)

### Часть V: Продвинутые техники (главы 18–21)
18. Парсинг и предметно-ориентированные языки (Megaparsec)
19. GADTs и семейства типов
20. Линзы и оптики (lens)
21. Куда двигаться дальше

### Приложения
- **Приложение A:** Графика с библиотекой gloss
- **Приложение B:** Интерфейс внешних функций (FFI)
- **Приложение C:** Внутренности GHC

## Требования

- [Stack](https://docs.haskellstack.org/) — сборка проекта (resolver: `lts-22.44`, GHC 9.6.7)
- [mdBook](https://rust-lang.github.io/mdBook/) — генерация HTML-книги
- [mdbook-admonish](https://github.com/tommilligan/mdbook-admonish) — preprocessor для врезок

## Быстрый старт

```bash
# Сборка всего (книга + упражнения)
./scripts/build-all.sh

# Сборка только упражнений
stack build

# Запуск всех тестов
stack test

# Тесты для конкретной главы
stack test chapter10

# Сборка HTML-книги
mdbook build
# Если mdbook не в PATH: ~/.cargo/bin/mdbook build

# Линтинг и форматирование
./scripts/lint.sh       # Проверка (hlint + fourmolu)
./scripts/format.sh     # Автоформатирование
```

## Работа с упражнениями

Каждая глава (кроме главы 1) имеет пакет с упражнениями:

1. Откройте `exercises/chapterNN/test/MySolutions.hs`
2. Замените `undefined` на свою реализацию
3. Запустите `stack test chapterNN`
4. Все тесты должны пройти ✅

Упражнения размечены сложностью:
- ★☆☆ — лёгкие (разминка)
- ★★☆ — средние (основная практика)
- ★★★ — сложные (челлендж)
